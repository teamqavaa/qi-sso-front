## Simplified Technical English

Use ASD-STE100 Simplified Technical English for all explanations in this repository.

- Use short sentences.
- Use the active voice.
- Use the present tense.
- Do not use "-ing" verb forms.
- Do not use unnecessary words.
- Give one instruction per sentence.
- Use "the user" instead of "you".

## Code comments

Add comments only when they add value. Follow these constraints:

1. Explain the "Why": Write comments that explain intent, business logic, edge cases, or hidden workarounds.
2. Do NOT explain the "What": Never comment self-explanatory code, basic loops, or standard variable assignments.
3. Keep it brief: Use short, punchy phrases. Do not exceed two sentences per comment block.
4. Use standard tags: Use TODO: for incomplete work and FIXME: for known bugs.
